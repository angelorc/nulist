Logs and the audit log filter through a facet sidebar with live counts per value, and every time-based view (logs, audit log, dashboard) has a date range picker with presets and custom ranges. Numbers across contacts, lists, segments, broadcasts, transactional, API keys, suppressions and webhooks link to the matching logs. Code and JSON blocks gain syntax highlighting, line wrapping, an expanded view and tidier scrolling.
